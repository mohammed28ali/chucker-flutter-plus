# Changelog

## 0.1.0

- Added Dio and `package:http` adapters for capturing requests and responses.
- Added the in-app inspector, request filtering, body sizes, copy, cURL, and sharing.
- Added configurable in-app banners and system notification delivery.
- Added bounded local history, retention, and sensitive-header redaction.
- Added the shared `NetworkLogger` with Dio, Chopper, and HTTP adapters.
